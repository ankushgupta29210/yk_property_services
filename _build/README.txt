YK Property Services - how this site is built
=============================================
The .html pages in the main folder are generated by build.py so every page
shares the same header, footer, menus and assistant.

To change text, services, FAQs, phone numbers etc:
  1. Edit _build/build.py (all page content lives there)
     - styles: _build/base.css (your original design) + _build/additions.css
     - interactive features: assets/site.js (edit directly)
  2. Run:  python _build/build.py
     It rewrites the pages and assets/styles.css in the folder above _build.

Reviews: add real customer reviews to the REVIEWS list at the top of assets/site.js.
Photos: to swap an illustration for real photos, put two <img> tags (class "before"
and "after") inside a <div class="ba">. Folders starting with "_" are not published by GitHub Pages.
